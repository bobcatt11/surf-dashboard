# Surf Dashboard

A simple surf forecast page for Old Man's (Tourmaline), San Diego.
Built with plain HTML, CSS and JavaScript. Hosted on GitHub Pages from the main branch.
Data comes from the free Open-Meteo marine and forecast APIs (no API key).

## About me
- I'm a beginner learning to code. Explain what you changed and why, in plain language.
- If there's a simpler way to do something, prefer it over a clever one.

## How to work
- Make one small change at a time, not several features at once.
- Before editing, tell me your plan in a few bullet points.
- Don't add frameworks, libraries or build tools (React, npm, etc.) without asking me first.
- Keep HTML, CSS and JavaScript in separate files (index.html, style.css, script.js) once the page grows.
- Add short comments explaining what each section of code does.
- Use clear, descriptive names for variables and functions (waveHeight, not wh).

## Quality
- If the forecast fails to load, show a friendly message on the page instead of breaking.
- Make the page readable on a phone as well as a laptop.
- Use readable text sizes and good colour contrast.
- Never put passwords, API keys or personal info in the code. This repo is public.

## Git
- Show me what changed before committing.
- Stage files by name, not with `git add .`.
- Write short, clear commit messages that say what changed (e.g. "Show wave direction as compass points").
- Only commit and push when I say "ship it". Never force-push.
- Remind me to check the page in my browser before pushing, since every push updates the live site.
